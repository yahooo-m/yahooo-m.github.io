Abstract

What should change?

A mask can pick out a person and miss their reflection. An instruction can name a subtitle without saying where it appears. EraseAnything uses either cue to select a target and learns from paired clean video how far the edit should extend.

One diffusion transformer reconstructs the full frame in four updates. Training gives extra weight to changes beyond the object mask and teaches the model to locate overlays from an instruction. Throughout reconstruction, the source video provides a stable reference for the surrounding scene.

Method

Select the target.
Reconstruct the scene.

A mask can miss a shadow. An overlay instruction gives no coordinates. Paired clean video teaches the model which pixels should change and which should stay.

Learn the complete edit

Differences between the input and paired clean video give extra weight to associated changes such as shadows and reflections.

Localize from an instruction

A training-only occupancy head teaches intermediate features to locate overlays when the input mask is empty.

Keep source evidence stable

Asymmetric attention lets the reconstruction read source and selection features. Training through four updates optimizes the delivered output.
